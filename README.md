# 🎮 Tic Tac Toe – Cyber Neon Wave Edition

A modern and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## ✨ Features

- 🎯 Interactive Tic Tac Toe gameplay
- 🤖 Single-player mode
- 👥 Two-player mode
- 🌌 Cyber/neon-inspired user interface
- 📱 Responsive design
- ⚡ Smooth and interactive gameplay
- 🧠 JavaScript-based game logic

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Choose a game mode.
2. Select your symbol.
3. Take turns placing X or O on the board.
4. Get three matching symbols in a row, column, or diagonal to win.
5. Restart the game and play again.
